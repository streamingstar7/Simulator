# 장보고-N LEU 원자로 재장전 횟수 최적화 시뮬레이터

DSTAC S3 TD 4부 가설("주기적 재장전이 무재장전보다 선체 크기와 비용 면에서 합리적이다")을 검증하는 웹 시뮬레이터다. 재장전 횟수 N을 0회부터 바꿔 가며 노심 크기, 선체 무게, 척당 추가 비용을 계산하고 비용이 가장 작은 N을 찾는다.

## 폴더 구성

```
code/
├── index.html                   화면 뼈대(패널, 탭, 표와 그래프 자리)
├── css/style.css                화면 스타일
├── js/model.js                  계산 모델(문헌 값, 기본값, 계산 함수)
├── js/app.js                    화면 동작(입력 처리, 그래프, 표, 탭)
├── vendor/plotly-2.35.2.min.js  그래프 라이브러리(인터넷 없이도 동작하도록 포함)
├── README.md                    이 파일
├── 코드_설명.md                 조원용 코드 해설
└── 배포_방법.md                 GitHub Pages로 사이트 주소 만드는 방법
```

## 실행

- 가장 쉬운 방법: `index.html`을 더블클릭해 브라우저로 연다.
- 글꼴(Pretendard)만 인터넷에서 받는다. 인터넷이 없으면 맑은 고딕으로 표시된다.
- 로컬 서버로 확인하려면 이 폴더에서 아래 명령을 실행하고 `http://localhost:8000`을 연다.

```bash
python -m http.server 8000
```

## 파일 하나짜리 버전

상위 폴더의 `7 장보고-N LEU 재장전 민감도 시뮬레이터.html`은 이 폴더의 내용을 파일 하나로 합친 것이다. 메일이나 메신저로 보낼 때 쓴다. 코드를 고칠 때는 이 `code` 폴더를 기준으로 한다.
